# 这一餐 · 互动餐桌

An independent, buildless static website with a floral glass cup, a dinner plate, cookies, and food interactions.

## Deployment

The primary deployment uses GitHub Pages from `main` / `docs`. Publish `docs/` as the website root. `render.yaml` remains an optional static-host configuration. No API keys, backend, database, external account login, or build dependencies are required.

The original approved version-17 layout and application code are retained. The public package contains only the page, its runtime assets, and attribution/license files.
